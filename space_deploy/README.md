# 🇹🇭 OpenThai-NER (Live Web Demo)

Interactive demonstration of **OpenThai-NER**, a state-of-the-art Named Entity Recognition model for the Thai language fine-tuned on multi-domain corpus.

- **Base Model:** `Pavarissy/phayathaibert-thainer`
- **Dataset:** `JonusNattapong/OpenThai-NER-Corpus`
- **GitHub Repository:** [JonusNattapong/OpenThai](https://github.com/JonusNattapong/OpenThai)
- **Supported Entity Types:** `PERSON`, `ORGANIZATION`, `LOCATION`, `DATE`, `TIME`, `MONEY`, `PERCENT`, `LAW`, `PHONE`, `EMAIL`, `URL`, `ID`, `FACILITY`, etc.
